# 前工程
実装開始後から、PRごとにCodexレビューを走らせコード解析を実施。
UI/UX等軽微な項目以外は全て解消してからマージすることでコード単位の品質を担保。

# 単体テスト
開発者に単体テストを作成し、実行してからPRしてもらう。
単体テスト生成用のSkillはQA側で用意する。

# Mutation Testing
単体テストコードの精度向上を目的として実行する。常にKILL率80%↑をキープ。

# リリーステスト
機能ごとにテストを実施する。(ある程度の機能のまとまりで区切り、実施回数は抑える)
実施前にテスト仕様書を作成し、それに基づいてClaudeで実行する。ただし、クリティカルのみ手動でも実行する。

# 回帰テスト
開発の進行にあわせて完了した機能の仕様変更が生じた場合、完了したテスト仕様書を修正し、再度テストを実施する。

# 結合テスト
テスト仕様書に基づいて実施。開発の段階が完了するごとに実施する。

# システムテスト
開発完了時に実施
機能テスト・性能テスト・負荷テスト・セキュリティテスト
